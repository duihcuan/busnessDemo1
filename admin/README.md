# 管理后台

## 运行

1. 启动后端（backend，端口 8080）。
2. `npm install && npm run dev`，浏览器打开 http://localhost:5173 。
3. 登录：admin / 123456（管理员）。

## 演示脚本

1. 仪表盘查看统计
2. 商品管理：新增/编辑/上下架/删除
3. 订单管理：对"已支付待发货"订单发货，可退款
4. 直播管理：新建直播间、开播/下播、挂载商品
5. 溯源维护：新增/编辑/删除溯源记录
6. 知识库：文档增删改（自动切分）、问答测试（带来源）、查看用户反馈

## 校验

```bash
node scripts/smoke.js && npm run build
```
